How it works — at a glance

Data Layer

Database tables

All data lives in Supabase (PostgreSQL). The AI features read student context from these tables and write outputs back. Understanding these tables explains what inputs drive AI quality.

1
university_programs — curated program database
Internal list maintained by the 1%abroad team. This is the "verified" source of truth.

Key columns: university_name · program_name · country · tuition_fee · app_closing_1 (deadline) · qs_ranking · gpa · scholarship_options · is_partner · acceptance_rate · program_link · application_fee

Used by: Chat Agent tool (primary query target) · Program Finder Step 3 (verification + data override)

Impact: Every program in this table that matches an AI result gets a verified badge and has its tuition/deadline overridden with accurate data. Programs not in this table are shown with AI-researched data only. Adding more programs here directly improves result quality.
2
student_profile_forms — detailed student profile
Filled by student after onboarding. Unlocks Program Finder and Report generation.

Key fields: education history (degree, institution, GPA) · test scores (GRE V/Q/AWA, GMAT, IELTS, TOEFL) · work experience (years, role, industry) · target program (degree, major, intake, budget min/max) · career goals · additional notes

Used by: All 4 AI features (injected as profile context) · Perplexity query builder · Report generation gate (submitted_at must be set)
3
onboarding_answers — quick profile from sign-up
Collected during the onboarding flow. Simpler/shorter than the full profile form.

Key fields: degree · destinations (array) · start_year · field_of_study · cgpa · budget · state · city

Used by: Perplexity query builder (primary source for country + intake + field) · Chat Agent context · Profile text formatter

Fallback role: If student_profile_forms is incomplete, onboarding answers fill the gaps so AI features still work partially
4
ai_profile_evaluations — generated reports
Stores every Profile Development Report generated.

Key columns: student_id · report_markdown (full report text) · perplexity_research (raw Perplexity output stored for reference) · triggered_by · created_at

Used by: Chat Agent — loads the latest report as permanent context for every conversation. Service team — can review what was recommended to a student.
5
ai_chat_messages — conversation history
Stores every message in every student conversation.

Key columns: student_id · role (user / assistant) · content · created_at

Used by: Chat Agent — loads last 20 messages as history so conversations feel continuous across sessions. Both user messages and AI responses saved after each exchange.
6
leads — student program interest
Created when student clicks "I'm interested" on a program card in Program Finder.

Key columns: user_id · program_id · status (starts as "new")

Used by: Service team queue — this is the handoff point where AI ends and human service begins. A lead record means a student has self-expressed interest in a specific program.

What drives AI output quality

The AI is only as good as the data it receives. In order of impact:

1. Completeness of student_profile_forms — more fields filled = better Perplexity query = better program matches = better report
2. Size of university_programs table — more programs curated = more verified results = more trust signals for students
3. Whether a Profile Report has been generated — once it exists, chat quality improves significantly because GPT-4o has a full structured assessment as context

How it actually works

Think of the AI like a very smart assistant sitting between the student and a stack of information. Here's what it does.

💬 The Chat

Student asks a question. The AI answers.

Before answering, the AI reads:

📋 The student's profile — their grades, budget, test scores, which countries they want
📄 Their full profile report — if they've generated one
💬 The last 20 messages in the conversation — so it remembers context

If the student asks "what programs suit me in Germany?" — the AI doesn't guess. It searches our own database of universities and pulls real results. Then answers using those.

Think of it like a counsellor who can instantly look up a list of universities mid-conversation.

🔍 Program Finder

Student clicks "Find Programs". Three things happen in order:

1
Search the internet
An AI called Perplexity goes live on the web and finds current programs — with today's deadlines, fees, and scholarship info. Not old data from training.
2
Clean it up + score it
GPT-4o reads the raw search results and turns them into a tidy list. It also scores each program 1–10 based on how well it fits that specific student's profile.
3
Check our own database
If a program found online also exists in our curated internal list, it gets a verified badge and its data is overridden with our confirmed info. These show first.
📝 SOP Analyzer

Student uploads or pastes their essay. The AI reads it and gives feedback.

It checks 9 things — like whether the opening is interesting, whether the student explains why this specific university, whether their goals make sense, whether the grammar is clean.

It gives a score out of 10, lists what's good, what's weak, and what to fix.

Nothing gets saved. Every analysis is fresh. It's like handing your essay to a consultant and getting notes back immediately.

📊 Profile Report

The biggest output. Student clicks "Generate My Report". Two things happen:

1
Research live scholarships
Perplexity searches the web for current scholarships — DAAD, Erasmus+, Holland Scholarship — with real deadlines and amounts.
2
Write the full report
GPT-4o writes a structured assessment: what's strong in the profile, what's weak, what to improve, which universities to target (Dream / Reach / Safe), and a step-by-step action plan.
Once the report is saved, the Chat Agent reads it automatically — so every future conversation the student has is informed by their full assessment. The report makes the chat smarter.
The whole thing in one sentence
Student fills their profile → AI searches the internet for real programs and scholarships → GPT-4o reads everything and gives personalised recommendations, scores their essay, writes their full assessment, and remembers it all in chat.
